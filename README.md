# 游戏校招情报助手 · 原型交付

面向 27 届游戏美术方向（场景美术 / 地编）的个人校招情报站 + AI 简历优化工具。

## 文件清单

| 文件 | 说明 |
|---|---|
| `需求文档.md` | 完整 PRD：功能需求、页面架构、数据模型、技术方案、里程碑 |
| `index.html` | 可点击原型（纯静态单文件，含模拟数据） |

## 如何打开原型

两种方式任选：

1. **一键启动（推荐）**：双击 `启动网站.bat`，浏览器会自动打开 `http://localhost:8000/`，网站就以正式网址形式运行；关闭弹出的黑色窗口即停止。
2. **直接打开**：双击 `index.html`，或拖入浏览器打开（单文件模式）。

无需安装任何环境，手机连同一 Wi-Fi 时也可以访问（地址为电脑的局域网 IP + 8000 端口）。

## 分享给别人（公开链接）

双击 `分享网站.bat`，脚本会启动本地服务并建立一条免费的公开隧道，然后把公开地址自动复制到剪贴板并打开浏览器。任何人在浏览器打开该地址即可访问，无需安装任何东西。

注意：

- 链接仅在**本电脑开机且窗口未关闭**时有效；
- 免费隧道每次重新启动会生成新的地址；
- 页面数据已完整内嵌在 `index.html` 中，即使数据服务关闭也能正常浏览。

### 长期稳定托管（可选）

如果想得到一个长期不变的地址，可以把 `index.html` 拖到 [Netlify Drop](https://app.netlify.com/drop) 免费发布，无需注册 GitHub、无需保留电脑开机。页面所有数据均已内嵌，部署后即可完整使用。

## 原型包含的页面

- 作战首页：今日概览、未来 30 天关键节点、紧急截止、最近上线
- 岗位库：38 家游戏公司（大厂/中厂/独立工作室）27 届校招模拟数据，支持实时搜索、方向/城市/规模/状态筛选与排序
- 实习招聘：20 家公司的 28 届实习岗位，长期开放岗位单独标注，同样支持实时搜索
- 岗位详情：招聘时间线、JD 关键词（绿色=已覆盖）、公司档案
- 简历诊断：上传简历 → 选择目标岗位 → 模拟 AI 分析 → 五维评分 + 逐条建议 + 作品集清单
- 投递看板：状态流转（未投递 → 已投递 → 笔试 → 面试 → Offer / 感谢信）
- 站内提醒：新岗位、截止、笔试面试提醒
- 设置：提醒开关、求职偏好、简历文件库

网申截止倒计时在岗位卡片、岗位详情和首页时间线三处均会突出显示（绿色=时间充裕、黄色=7 天内截止、红色=3 天内截止并带脉冲提示）。

## 数据说明

当前招聘信息为**演示模拟数据**（基于 2026 秋招窗口）。已提供本地数据服务（M1），连接后前端会自动使用后端数据，支持手动录入与来源检查。

## 数据服务（M1）

`backend/` 目录为本地数据服务，纯 Python 标准库实现，无需安装依赖：

```bash
# 1. 生成种子数据（从 index.html 提取，已内置 38 家校招 + 20 家实习）
python backend/extract_seed.py

# 2. 启动数据服务（端口 8001）
python backend/server.py

# 3. 浏览器访问前端（会自动连接 8001；连接失败时回退到内置数据）
双击 启动网站.bat

# 4. 检查各公司官网连通性（发现失效链接 / JS 页面）
python backend/crawler.py check --limit 8

# 5. 手动录入单条数据（POST /api/manual/add）
# 6. 简历 AI 分析（POST /api/analyze；设置 DEEPSEEK_API_KEY 后启用真实调用）
# 7. 采集官网真实数据（米哈游 / 网易雷火 / 腾讯 IEG）
python backend/collect.py
python backend/collect.py --watch 6   # 每 6 小时自动采集一次
```

常用接口：`GET /api/health`、`/api/jobs`、`/api/interns`、`/api/companies`、`/api/stats`。

**已接入的官网数据源**：

| 公司 | 数据量 | 方式 |
|---|---|---|
| 腾讯 IEG | 899 条（校招 386 / 实习 513） | 官方接口直采 |
| 米哈游 | 258 条（校招 118 / 实习 140） | 官方接口直采 |
| 网易雷火 | 52 条（27 届应届校招） | 官方接口直采 |
| 其余 35 家 | 种子演示数据 | 待逐站接入 |

**当前进度**：三家大厂已完成真实采集（数据与官网数字一致）；采集器支持 `--watch` 定时循环。后续可继续接入其余公司，并把定时采集挂到 Windows 任务计划程序。

## 原型 vs 正式版

- 原型数据为**模拟数据**（日期基于 2026-08-07 秋招窗口），正式版由采集器自动同步 + 人工录入
- 简历分析目前是**本地模拟流程**，正式版接入 DeepSeek V4 Flash API 做语义分析
- 站内提醒目前为静态示例，正式版由定时任务按截止时间自动生成
